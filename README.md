# 星露谷物语桌面宠物 (Stardew Desktop Pet)

一款专为 Windows 打造的纯原生星露谷物语（Stardew Valley）风格桌面宠物应用。基于 Windows .NET Framework 分层透明窗口（Per-Pixel Alpha）与无锯齿像素缩放绘制，零外部依赖，双击 `StardewPet.exe` 即可运行！

## 功能特色

- **14 位星露谷桌面伙伴**：
  - 祝尼魔（苹果绿 / 草莓粉 / 蓝莓蓝 / 柠檬黄 / 葡萄紫）
  - 谢恩的蓝鸡 / 鹈鹕镇白鸡
  - 果冻史莱姆 / 科罗布斯
  - **农场猫猫**（舔爪、趴下、睡觉、坐下、抬头）
  - **塞巴斯蒂安 / 艾米丽 / 阿比盖尔**（看书、跳舞、喝咖啡、抬头看天，16×32 人物像素素材）
  - **熔炉**（安静燃烧的炉火，支持"烧掉烦恼"）
- **多角色动作切换（参考 kele-desktop-pet 的状态机思路）**：
  - 右键托盘或宠物 → `🎬 切换动作`，按当前角色列出可用动作
  - 动作带权重自然过渡：走路 → 发呆 / 趴下 / 舔爪 / 睡觉；人物 → 坐下 / 跳舞 / 喝咖啡 / 抬头
  - `🎲 随机来一个动作` 按角色偏好抽取特色动作（猫猫舔爪、艾米丽跳舞、塞巴斯蒂安喝咖啡……）
  - 人物角色采用 16×32 帧尺寸，猫猫与熔炉各有独立帧尺寸，窗口尺寸自动适配
- **🔥 熔炉 · 烧掉烦恼**：
  - 托盘选择 `🔥 打开熔炉 · 烧掉烦恼` 或直接切换到熔炉角色并双击
  - 木框便签最多 200 字，写下不开心的事，点击"烧掉烦恼"后炉火跳动、灰烬上升
  - 约 3 秒后烦恼清空并提示"已化成灰烬"，内容不会写入磁盘
- **自然交互与物理效果**：
  - **左键单击**：抚摸宠物，触发爱心粒子、复古音效与星露谷风格对话气泡
  - **左键按住约 2 秒**：头上冒出 `💬` 省略号后受惊飞快逃跑（熔炉太沉，搬不动）
  - **左键快速晃动拖拽**：头上冒出 `😵` 一团乱麻眩晕表情
  - **左键慢速拖拽**：把宠物移动放到桌面任意位置（关闭「桌面自由漫步」则重力回落到任务栏）
  - **左键双击**：打开星露谷木框风格的「宠物日记」，查看好感度（♥）与今日占卜；熔炉则打开烧烦恼便签
  - **放置干草/食物喂食**：右键托盘或宠物 → `🌿 放食物到桌面喂食`，食物跟随鼠标，左键放置后宠物自动跑去吃掉并露出 `😊` 笑脸
  - **键鼠共舞与统计**：敲击键盘或点击鼠标时，宠物脚下出现复古像素键盘并踩着节拍跳舞；本地统计今日/累计键鼠次数、手速与近 7 日柱状图（绝不记录按键内容）
  - **鼠标穿透与详细设置**：可开启 `👻 鼠标穿透`（通过托盘随时关闭），调节大小（2x~5x）、移动速度、活跃度（1~10）、显示/隐藏及开机自启
- **配置与统计保存**：偏好设置保存至 `%APPDATA%\StardewDesktopPet\config.ini`，键鼠统计保存至 `%APPDATA%\StardewDesktopPet\stats.ini`。

## 编译与运行

直接双击运行目录中的 `StardewPet.exe`，或者运行 `build.bat` 重新编译：

```bat
build.bat
```

可选自检（验证全部角色 × 动作 × 帧尺寸、表情、动作目录与键鼠统计）：

```bat
StardewPet.exe --self-test
```

> 自检成功会输出 `SELF_TEST_OK: 14 pets x 12 anims x 2 frames + 12 emotes + action catalog verified.`
